# 插件总览

[← 文档首页](../README.md)　·　[← 返回项目 README](../../README.md)　·　中文　·　[English](../en/plugins/README.md)

核心（agent / session / server / llm）不含任何具体工具，能力一律由插件提供。插件的开关与配置在 Web UI 的设置页（或远程机器上的 `wen config plugins`）里维护，改动即时生效，不写进 config.yaml。

插件发给模型的一切——注入的提示词、块名、工具说明与参数——**跟着 `lang:` 走**（见[配置与模型](../configuration.md#语言)）。可编辑的提示词（心跳提示词、兜底台词这些）连默认值一起：英文下文本框预填的是英文版，点「恢复默认」也回到英文版。

**开箱就是一个角色。** 除下表标「关」的十二个之外全部默认启用，`roleplay` 自带一份默认角色设定与台词样例——不改任何配置直接聊，对面就是一个有性格、有生活、会主动开口的人，而不是一个通用助手。不想要就在设置页改设定或整组关掉。

| | `skills` | 按需读取的技能手册（SKILL.md） | 关 |
| [角色演绎](roleplay.md) | `roleplay` | 角色设定、台词样例、自然表达与时间一致性约束 | 开 |
| | `dual_persona` | 表里两套人格，由触发词切换，记忆与历史互不可见 | 关 |

| [角色的生活](life.md) | `scene` | 舞台设定与场景记忆 | 开 |
| | `weather` | 按城市取现实天气，作为环境状态每轮注入 | 关 |
| | `belongings` | 冰箱、衣柜里有什么 | 开 |
| | `people` | 角色的社交圈：朋友、家人、亲近度与他们的近况 | 开 |
| | `agenda` | 每天给自己排一张表，到点去做；约定与「答应过的事」台账 | 开 |

| | `phone` | 闲下来时刷一刷你配的订阅源，碰上感兴趣的会跟你提 | 关 |

| | `mood` | 心情随互动增减、随时间回落 | 开 |

| | `presence` | 此刻的所在、穿着、姿态与正在做的事 | 开 |

| | `scheduler` | 定时任务（一次性 / 周期 / 每日） | 开 |
