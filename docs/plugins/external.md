# 外源插件

[← 插件总览](README.md)　·　[← 文档首页](../README.md)　·　中文　·　[English](../en/plugins/external.md)

这一节里的东西与其它插件不同：`bundles` 是内置的管理入口，而它下面那些 `ext_` 开头的卡片，是你自己装进来的插件包，装几个就有几张。

外源插件走 [Agent Plugins 1.0](https://agent-plugins.org/) 标准——2026 年 8 月由 OpenAI、微软、AWS、Cursor 与 Vercel 联合发布的插件包格式，ChatGPT、Codex CLI、Cursor、GitHub Copilot、VS Code 共用同一批插件包。一个包是一个目录，根下有 `plugin.json`，可以带 `skills/`（技能手册）与 `mcp.json`（MCP server 声明），**不含任何可执行代码**。命令行的完整用法见[命令行](../cli.md#wen-plugins装外源插件包)。

## `bundles`：安装入口

| 配置项 | 默认 | 说明 |
|---|---|---|
| `source` | 空 | 要安装的插件包：本机上的一个目录或 `.zip` 路径 |

两个操作：**安装**（装 `source` 里填的那个包，装完连一次它声明的 MCP server 取工具清单）与**重新握手全部**（把已装的每个包都连一遍，工具清单重取）。

`source` 只认**服务所在机器上的路径**——浏览器里的文件传不过去。远程部署时先把包传到那台机器上，再填路径。卸载没有做进界面，用命令行：`wen plugins uninstall <名称>`。

这个插件不给模型任何东西：不注入提示词，也不提供工具。

## `ext_*`：装进来的插件包

每个装好的包在设置页上占一张卡片，名字是 `ext_` 加包名（插件名全局唯一且会被拼成目录名，一个叫 `memory` 的包否则会与内置的记忆插件撞名）。卡片可以单独开关，关掉它，这个包带的技能与工具就都不生效。

| 配置项 | 默认 | 说明 |
|---|---|---|
| `confirm` | 关 | 调用前确认。外源工具能做什么由对方决定，拿不准时先开着 |
| `max_result_bytes` | 16384 | 单次结果最多保留的字节数，超出截断 |

一个操作：**重新握手**，只连这一个包。

**装完与卸完都要重启服务**：插件在启动期一次性注册，注册顺序还承载着提示词的拼接顺序。

### 技能

包里 `skills/` 下的每个子目录是一篇技能手册，与你自己写的技能进**同一份清单**、共用同一个 `read_skill`。它们要等 [`skills`](memory.md) 插件打开之后才会进清单——它默认是关的。

### MCP 工具

包里 `mcp.json` 声明的 server 提供的工具进入模型的工具表，工具名的形状是 `<包名>_<server 名>_<工具名>`。支持 stdio（本机子进程）、Streamable HTTP 与已废弃的 HTTP+SSE 三种传输。

**工具清单在安装时取一次并存下来**，不是每次启动现问——插件在注册时就要交出工具清单（程序要查全局重名），在那一步为每台 server 起一个子进程握手，会让服务每次启动都停上好几秒。包更新了、依赖后来才装好、上次没连上，用「重新握手」重取。

子进程按需拉起：装完之后没人调用的话，一个进程都不会起。

每台 server 都会拿到标准规定的两个环境变量：`PLUGIN_ROOT` 指向包目录，`PLUGIN_DATA` 指向 `plugins/<插件名>/data/`。后者跨卸载重装保留——server 攒在里面的索引与缓存不该跟着包一起消失。

### 也认别家的插件包

Claude、Codex、Cursor 的插件包格式比 Agent Plugins 出现得早，社区里已经有很多。它们的清单在 `.claude-plugin/plugin.json` 这类位置、没有 `$schema`，但内容的固定位置是一样的，因此也认——**只读得懂里面的技能与 MCP 声明**，那些格式特有的东西（命令、子代理、钩子）不会生效，装的时候会说明一句。

## 安全

装一个插件包意味着**将来会在你的机器上执行它声明的命令**，取工具清单那一步当场就会执行一次。命令原文在安装时会打出来给你看。命令行里可以用 `--no-connect` 先装不连。

压缩包里指向外部的路径（`../`）与符号链接一律拒绝；解包有大小与文件数上限；插件包里的每一条路径都必须落在包目录之内。校验在复制之前完成，装一个坏包不会在配置目录里留下残骸。

`mcp.json` 里直接写着 `Authorization`、`Cookie` 这类头时会提醒一句：插件包是拿来分发的，写在里面的凭据等于公开的凭据。提醒而不拦——那是包作者的选择。
